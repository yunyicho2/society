# 운영 안내 (담당 선생님용)

코드를 몰라도 됩니다. 거의 모든 것은 **학교 구글 시트**에서 고치고, 카드 링크만 GitHub에서 고칩니다.

학교 시트: "현대고 온라인 교무실 데이터". 사이트의 **관리 → 학교 시트 열기**로 열 수 있습니다.

## 공통 규칙
- 모든 탭은 **1행 제목, 2행 안내, 3행 머리글, 4행부터 자료**입니다. 1~3행은 지우지 마세요.
- **연한 파란 칸**에 입력합니다.
- `요일` 열은 날짜를 넣으면 자동으로 채워지니 비워 둡니다.
- 비고에 `예시` 또는 `예시 행`이라고 적힌 줄은 사이트가 무시합니다.
- 고친 내용은 **1분 안에** 사이트에 반영됩니다.

## 탭별 담당

| 탭 | 담당 | 무엇을 | 사이트에서 |
|---|---|---|---|
| 권한 | 정보 담당 | 개인 지메일 · 이름 · 역할 | 로그인, 역할별 버튼 |
| 전체시간표 | 시간표 담당 | 교사 1명당 월~금 5줄, 칸에 `과목 학급` (예: `국1 1-3`, `탐A 316호`, `창체`) | 내 시간표, 진도, 교체 추천 |
| 학사일정 | 교무기획부 | 수업 없는 날·교시 | 진도 계산, 오늘의 일정, 아침 안내 |
| 당번표 | 교무부장 | 감독 교사 이름 | 아침 안내 메시지 (교무부장만 보임) |
| 월중계획 | 각 부서 | 연수·회의 등. `아침 안내 포함` 체크 | 오늘의 일정, 아침 안내 |
| 업무분장 | 교무기획부 | 부서 · 업무 · 담당자 · 세부 업무 (세부 업무는 한 칸에 줄을 바꿔 적음) | 규정 챗봇의 "누가 담당해요?" 답 |
| 관리자일정 | 교무부장 | 교장·교감 출장 등 | 오늘의 일정 |
| 대강교체 | 사이트가 자동 기록, 수업계가 확정 | 상태: 결재 대기 / 확정 / 반려 / 취소 | 대강·교체 현황 |
| 그외자료 | 사이트가 자동 기록 | 직접 추가할 때는 드라이브 링크 붙여 넣기 | 그 외 자료 |

### 권한 탭 역할 쓰는 법
`교사`, `시간표 담당`(또는 `수업계`), `교무부장`, `정보 담당`, `관리자` 중에서 고릅니다. 여러 개면 쉼표로 이어 씁니다(예: `교무부장, 정보 담당`). 모든 사람은 기본으로 `교사` 권한을 가집니다.

### 학사일정 탭 쓰는 법
- **대상 학년**: `전체`, `3학년`, `1·2학년`
- **수업 없는 교시**: `전체`, `3~7교시`, `1,2교시`. 수업은 그대로 하는 행사(예: 합창페스티벌 당일 오후만 행사)는 실제로 빠지는 교시만 적고, 수업이 안 빠지면 `없음`
- 같은 날 학년마다 다르면 줄을 나눕니다. 예: 11/18 수능 출정식은 아래 두 줄로 씁니다.

| 날짜 | 내용 | 대상 학년 | 수업 없는 교시 |
|---|---|---|---|
| 11/18 | 수능 출정식 | 1·2학년 | 3~7교시 |
| 11/18 | 수능 출정식 | 3학년 | 전체 |

- 같은 내용이 며칠 이어지면(시험 기간) 날마다 한 줄씩 씁니다. 사이트가 하나로 묶어 보여 줍니다.

## 수업 변경(대강·교체) 흐름

1. **교사**: 나이스 복무 신청을 합니다.
2. **교사**: 사이트 **수업 변경 신청**을 엽니다.
   - 복무 시각을 넣으면 그 시간과 겹치는 수업만 결강으로 잡힙니다.
   - 추천 교체를 고르고 상대 선생님과 협의합니다.
   - **신청 등록**을 누르고 **HWPX 받기**로 신청서를 출력해 수업계에 냅니다.
3. **수업계**: 대강·교체 현황의 **결재 대기** 탭에서 **확정**을 누릅니다. 안 되는 신청은 **반려**합니다.
4. **교사**: 나이스 복무 최종결재를 받습니다.

- 결재 대기 상태에서는 신청한 교사가 **취소**할 수 있습니다. 확정된 뒤에는 수업계에 말해야 합니다.
- 시트에서 직접 고쳐도 됩니다. 상태 칸만 바꾸면 됩니다.

## 카드 링크 바꾸기 (정보 담당)

1. GitHub에서 `dashboard/public/config/dashboard.json`을 열고 연필 아이콘을 누릅니다.
2. **따옴표 안 글자만** 바꿉니다. 줄을 추가할 때는 위 줄을 복사하고, 줄 끝 쉼표에 주의합니다.
3. **Commit changes**를 누르면 1~2분 뒤 반영됩니다. 문법이 틀리면 배포가 멈추고 기존 화면이 유지됩니다(Cloudflare 빌드 로그에 틀린 줄이 나옵니다).

```json
{ "label": "업무분장표", "url": "https://drive.google.com/..." }
```

### 학기가 바뀔 때
`dashboard.json`의 `term`을 고칩니다.

| 값 | 뜻 |
|---|---|
| `rangeStart` | 진도 범위 시작일 (정기고사 다음 수업일) |
| `progressEnd` | 진도 마무리일 |
| `examStart`, `examLabel` | 머리글의 D-day |
| `lastDay` | 방학식 (이후는 수업 없음) |

학년을 이름으로 알 수 없는 교실(예: `316호` = 2학년)은 `classGrade`에 적습니다.

## 규정 챗봇 문서 (정보 담당·관리자)
- **관리 → 규정 챗봇 문서**에서 HWP·HWPX·TXT 파일을 고르면 됩니다. 브라우저가 글자만 뽑아서 올립니다(학교교육계획서처럼 큰 문서도 됨). 암호가 걸린 문서나 배포용 문서는 한글에서 일반 문서로 다시 저장한 뒤 올립니다.
- 규정이 바뀌면 옛 문서를 **삭제**하고 새 문서를 올립니다. 남겨 두면 옛 내용으로 답할 수 있습니다.
- 학생 이름이 들어간 문서는 올리지 않습니다. 문서를 올릴 때는 주민번호·휴대전화·메일만 자동으로 가립니다. 교직원 이름과 업무분장은 답에 필요해서 그대로 둡니다.

## 선생님별 설정 (각자)
**내 설정**에서 아래를 정할 수 있습니다. 다른 선생님 화면에는 영향이 없습니다.
- 카드 숨기기·순서
- 진도 마무리일
- 담임 학급 (출결 서류에 학년·반 자동 입력)
- 진도 관리할 수업
- 과목 표시 이름 (예: `탐A` → `사회문화`)
- 요일별로 나누는 과목 (예: 통합사회 월화수 `정치`, 목금 `경제` → 영역마다 차시를 따로 셈)
- 화면 밝기
- 내 바로가기

**날짜별 지정** 탭에서 특정 날의 수업을 따로 정할 수 있습니다. 내 진도 계산에만 반영됩니다.
- **수행평가**: 그 시간은 차시에서 빼고 차시 진도표 아래 '수행평가' 줄에 표시 (예: 11/2~11/6, 과목 '통합사회')
- **다른 영역으로**: 그 시간을 다른 영역의 차시로 셈 (예: 11/30 1-6 통합사회(정치) → 통합사회(경제))
- **수업 없음**: 교체·개인 사정으로 빠진 수업 (예: 10/22 1-6 7교시)
- 기간·학급·과목·교시를 비우면 '전부'입니다. 추가하기 전에 해당 수업 목록이 미리 보입니다. 겹치면 나중에 넣은 지정이 우선입니다.

**내 시간표** 탭에서 편집으로 칸을 고치면 내 진도 계산에만 반영됩니다. 학교 시간표 변경은 시간표 담당이 `전체시간표` 탭에서 합니다.

## 내 메모 (각자)
- '오늘 한눈에'의 **내 메모**에서 **+ 새 메모**를 누르면 됩니다. 적으면 자동 저장되고, 다른 기기에서 로그인해도 같은 메모가 보입니다.
- 색을 바꾸거나 **고정**으로 맨 앞에 둘 수 있습니다. 한 사람당 60개까지입니다.
- 메모는 본인만 봅니다. 그래도 학생 이름·번호는 적지 마세요. 그런 글자가 보이면 메모 아래에 빨간 안내가 뜹니다.

## 학생 정보 다루기 (모든 선생님)
- 출결 서류 생성과 나이스 엑셀 읽기는 **내 PC 브라우저 안에서만** 처리합니다. 서버에 저장되거나 AI로 가지 않습니다.
- 받은 HWPX는 학교 규정대로 보관·파기합니다.
- 규정 챗봇·공문 도우미에는 학생 이름을 쓰지 않습니다. 써도 자동으로 가려지지만 습관을 들여 주세요.
- **그 외 자료**에는 학생 개인정보 파일을 올리지 않습니다(모든 교원이 봄).

## 자주 묻는 것

| 질문 | 답 |
|---|---|
| 새로 오신 선생님이 로그인이 안 돼요 | `권한` 탭에 개인 지메일 추가 → 1분 뒤 다시 |
| 시간표가 비어 보여요 | `권한` 탭 이름 = `전체시간표` 탭 이름인지 (띄어쓰기 포함) |
| 진도 차시가 이상해요 | `학사일정` 탭의 대상 학년·수업 없는 교시, `dashboard.json`의 `rangeStart` |
| 식단이 안 나와요 | 학교 영양실이 나이스에 식단을 올렸는지 (매달 초) |
| 아침 안내가 비어요 | `당번표` 탭에 그 날짜 줄이 있는지 |
