# 합리적 선택 실험실

고등학교 1학년 **통합사회 2 · 주제 13 「합리적 선택과 시장 실패」** 수업용 인터랙티브 학습 도구입니다.
`index.html` 파일 하나로 되어 있어 브라우저로 열기만 하면 바로 쓸 수 있습니다. 설치·서버·인터넷 연결이 필요 없습니다.

## 쓰는 법

- **수업 중**: `index.html`을 더블클릭해 열고 전자칠판에 띄웁니다.
- **학생 개별 활동**: 파일을 공유하거나 GitHub Pages로 배포해 링크를 나눠 줍니다.
  (저장소 Settings → Pages → Branch를 이 브랜치로 지정하면 `https://yunyicho2.github.io/society/` 에서 열립니다.)
- **교사 모드**: 우측 상단 버튼을 켜면 각 단계의 수업 팁과 자료 탐구 정답·해설이 나타납니다. 학생에게 보여 줄 때는 꺼 두세요.
- **화면 반전**: 교실 조명이 어두울 때 쓰는 명암 전환 버튼입니다. 기기 설정을 따라가는 것이 기본값입니다.

## 다섯 단계 구성

| 단계 | 내용 | 학생이 직접 조작하는 것 |
| --- | --- | --- |
| 01 기회비용 | 편익·명시적 비용을 바꾸면 암묵적 비용과 순편익이 실시간으로 다시 계산되고, 학습지 계산표가 그대로 채워집니다. | 대안 이름·편익·비용 슬라이더, 대안 추가(최대 4개) |
| 02 매몰비용 | 같은 상황을 세 가지 방식으로 계산해 봅니다. ①②는 결론이 같고 ③만 뒤집힙니다. | 상황 선택, 매몰비용 금액 슬라이더, 계산 방식 3종 |
| 03 시장 실패 | 독과점·외부 효과·공공재를 각각 그래프와 시뮬레이션으로 확인합니다. | 기업 수, 외부 효과 종류·크기, 무임승차 시뮬레이션 실행 |
| 04 재화 분류 | 경합성·배제성 2×2 판에 재화 8개를 분류합니다. 틀리면 힌트, 맞히면 해설이 나옵니다. | 재화 선택 → 칸 선택 |
| 05 자료 · 평가 | 학습지의 비만세·댐 건설 자료 탐구와 6문항 형성평가(즉시 채점·해설). | 자료 문항, 객관식 선택 |

### 수업 흐름 예시 (45분)

1. **01 단계** — 교과서 예시(X재 650/400, Y재 600/300)로 시작합니다. 계산표가 학습지 정답인 **X재 −50 · Y재 +50**과 그대로 맞습니다. X재 편익을 750으로 올려 결론이 뒤집히는 것을 보여 주세요. (10분)
2. **02 단계** — 콘서트 상황에서 계산 방식 ①→②→③ 순으로 눌러 봅니다. 매몰비용을 아무리 키워도 ①②의 결론이 바뀌지 않는다는 점이 핵심입니다. (8분)
3. **03 단계** — 기업 수를 1개까지 줄여 보고, 외부 효과 크기를 0으로 두었다가 올려 봅니다. 공공재는 '자율에 맡겨 보기'를 실행해 무임승차 연쇄를 보여 준 뒤 '세금으로 공급하기'와 비교합니다. (15분)
4. **04 단계** — 모둠별로 8개 분류를 겨루게 합니다. (5분)
5. **05 단계** — 자료 탐구 후 형성평가로 마무리합니다. (7분)

## 계산 규칙에 대한 안내

- 기회비용 = 명시적 비용 + 암묵적 비용, 순편익 = 편익 − 기회비용
- **암묵적 비용**은 교과서·문제집에 따라 *포기한 대안의 순편익*으로 보기도 하고 *편익 전체*로 보기도 합니다.
  01 단계 아래쪽에서 두 기준을 전환할 수 있으며, 기본값(순편익 기준)이 학습지 정답과 일치합니다.
- 03 단계의 그래프 수치는 개념 이해를 돕기 위한 예시 값이며 실제 시장 자료가 아닙니다.
  독과점 그래프는 수요 `P = 100 − Q`, 생산비 `20`을 가정하고 기업 수 n에 따른 균형을 계산합니다.

## 기술 메모

- 의존성 없는 단일 HTML 파일. 외부 자원은 Google Fonts뿐이며, 연결되지 않아도 시스템 한글 글꼴로 정상 표시됩니다.
- 그래프는 라이브러리 없이 SVG로 직접 그립니다.
- 명암 테마, 모바일(약 390px) 대응, 키보드 탐색(탭 좌우 방향키), `prefers-reduced-motion` 지원.
